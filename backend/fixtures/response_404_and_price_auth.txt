The price/quote API requires:
  1. Canvas fingerprint (browser-rendered canvas pixel hash)
  2. WebGL fingerprint
  3. Mouse movement trajectory data (min 8 frames, minDwellMs requirement)
  4. POST to an intermediate token endpoint (URL obfuscated in bundle)

Without satisfying the bot-detection challenge, the price endpoint returns:
  HTTP 429 Too Many Requests  ->  class Er (retryable)
